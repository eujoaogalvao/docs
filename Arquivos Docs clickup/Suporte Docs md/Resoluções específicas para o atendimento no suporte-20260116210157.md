# Resoluções específicas para o atendimento no suporte

*   **Não consigo colar/importar?**
    
    Siga esse passo a passo antes de fornecer a resposta:
    
      
    
    1. Responda o usuário da seguinte forma: “**Já fez as configurações iniciais do seu WordPress?**”
        1. Caso a resposta seja de negativa, você vai enviar a seguinte mensagem: “Vou te enviar o passo a passo para configurar” e enviar o link: [https://app.easybuilder.com.br/onboarding](https://app.easybuilder.com.br/onboarding) 
        2. Caso o usuário responda positivamente, responda o usuário da seguinte forma: “**Seu problema é só em colar as páginas ou as seções também?”**
        3. Se o problema for somente para colar as páginas ou em colar as seções e páginas, você vai responder com **“Vou te enviar um link para te ajudar a resolver”**, e enviar o link: [https://app.easybuilder.com.br/onboarding/?step=03](https://app.easybuilder.com.br/onboarding/?step=03)
        4. Caso o usuário responder que é somente com as seções você vai enviar esse link: [https://app.easybuilder.com.br/onboarding/?step=02](https://app.easybuilder.com.br/onboarding/?step=02)
        5. 
    2. Caso o usuário ainda persista com o erro você vai enviar esse link aqui: [https://app.easybuilder.com.br/onboarding/?step=04](https://app.easybuilder.com.br/onboarding/?step=04)
    3. 
    
    Se ainda não resolver, peça uma interversão de suporte humano.
