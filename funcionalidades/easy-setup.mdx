## O Que é o Easy Setup?

**Easy Setup** é um plugin WordPress que funciona como um **médico do seu site** - ele diagnostica problemas e corrige automaticamente configurações necessárias para o Easy Builder funcionar 100%.

<Info>
  **Instalou WordPress manualmente?** Easy Setup verifica se TUDO está configurado corretamente para usar Easy Builder sem erros!
</Info>

## Como Instalar

<Steps>
  <Step title="1. Baixe o plugin">
    Acesse o link acima e baixe o arquivo `.zip`
  </Step>

  <Step title="2. Instale no WordPress">
    **WordPress → Plugins → Adicionar Novo → Enviar Plugin**

    - Clique em "Escolher arquivo"
    - Selecione o `.zip` do Easy Setup
    - Clique em "Instalar Agora"
  </Step>

  <Step title="3. Ative o plugin">
    Após instalação, clique em **"Ativar Plugin"**
  </Step>

  <Step title="4. Acesse o painel">
    **WordPress → Easy Setup** (menu lateral)

    Painel de diagnóstico vai abrir!
  </Step>
</Steps>

<Warning>
  **Plugin se auto-deleta em 6 horas!** Após corrigir tudo, o plugin se remove automaticamente do seu WordPress. É temporário, só para setup inicial!
</Warning>

## O Que o Plugin Verifica?

### Status da Verificação (9 Checagens)

<AccordionGroup>
  <Accordion title="1. Plugin Elementor" icon="e">
    **Verifica:**
    - ✅ Elementor está instalado
    - ✅ Elementor está ativo
    - ✅ Elementor está atualizado

    **Se encontrar problema:**
    - Botão **"Instalar Elementor"** (se não instalado)
    - Botão **"Ativar Elementor"** (se desativado)
    - Botão **"Atualizar Elementor"** (se desatualizado)

    **Correção:** 1 clique!
  </Accordion>

  <Accordion title="2. Elementor Pro / ProElements" icon="crown">
    **Verifica:**
    - ✅ Elementor PRO OU ProElements está instalado
    - ✅ Está ativo

    **Se encontrar problema:**
    - Botão **"Instalar ProElements"** (baixa e instala automaticamente!)

    **Por quê importa:** Easy Builder precisa de funcionalidades PRO para importar templates complexos

    <Info>
      **ProElements = Grátis!** Plugin faz download automático de [ProElements.org](https://proelements.org)
    </Info>
  </Accordion>

  <Accordion title="3. Experimento: Contêineres Flexbox" icon="box">
    **Verifica:**
    - ✅ Recurso "Container" do Elementor está ativo

    **O que é:** Sistema moderno de layout do Elementor (substitui Section/Column)

    **Se encontrar problema:**
    - Botão **"Ativar Contêineres"**

    **Por quê importa:** Templates modernos do Easy Builder usam Containers!
  </Accordion>

  <Accordion title="4. Experimento: Elementos Aninhados" icon="layer-group">
    **Verifica:**
    - ✅ Recurso "Nested Elements" do Elementor está ativo

    **O que é:** Permite elementos dentro de elementos (aninhamento)

    **Se encontrar problema:**
    - Botão **"Ativar Elementos Aninhados"**

    **Por quê importa:** Templates avançados usam widgets aninhados
  </Accordion>

  <Accordion title="5. Tema Hello Elementor Ativo" icon="brush">
    **Verifica:**
    - ✅ Tema "Hello Elementor" está ativo

    **Por quê importa:**
    - Tema MAIS leve para Elementor
    - Zero conflitos
    - Perfeito para Easy Builder

    **Se encontrar problema:**
    - Botão **"Ativar Hello Theme"** (instala e ativa automaticamente!)

    **Alternativa:** Qualquer tema leve serve, mas Hello é o recomendado
  </Accordion>

  <Accordion title="6. Limite de Memória PHP (mín. 512M)" icon="memory">
    **Verifica:**
    - ✅ `memory_limit` ≥ 512M

    **Por quê importa:** Templates grandes precisam de memória para importar

    **Se encontrar problema:**
    - ❌ **NÃO corrige automaticamente** (precisa acesso ao servidor)
    - ✅ Mostra botão **"Ver Tutorial"** linkando para solução

    **Como corrigir:** [Ver guia completo](/resolucao-problemas/limite-memoria)
  </Accordion>

  <Accordion title="7. Max Input Vars PHP (mín. 100.000)" icon="list">
    **Verifica:**
    - ✅ `max_input_vars` ≥ 100000

    **O que é:** Quantidade de campos que podem ser enviados de uma vez

    **Por quê importa:** Templates têm muitos widgets (muitas variáveis!)

    **Se encontrar problema:**
    - Mostra **tutorial** de como aumentar no cPanel

    **Como corrigir:** [Ver guia completo](/resolucao-problemas/limite-memoria)
  </Accordion>

  <Accordion title="8. Post Max Size PHP (mín. 128M)" icon="upload">
    **Verifica:**
    - ✅ `post_max_size` ≥ 128M

    **O que é:** Tamanho máximo de dados enviados

    **Por quê importa:** Importar template grande envia muitos dados

    **Se encontrar problema:**
    - Mostra **tutorial** de como aumentar

    **Como corrigir:** [Ver guia completo](/resolucao-problemas/limite-memoria)
  </Accordion>

  <Accordion title="9. Tempo Máx. de Execução PHP (mín. 180s)" icon="stopwatch">
    **Verifica:**
    - ✅ `max_execution_time` ≥ 180 segundos

    **O que é:** Tempo máximo que script pode rodar

    **Por quê importa:** Importação de template demora (precisa de tempo!)

    **Se encontrar problema:**
    - Mostra **orientação** de como corrigir

    **Como corrigir:** [Ver guia completo](/resolucao-problemas/limite-memoria)
  </Accordion>
</AccordionGroup>

## Recurso Especial: Auto-Delete em 6 Horas

<Warning>
  **Plugin temporário!** Easy Setup se auto-deleta 6 horas após ativação.
</Warning>

### Por Quê Auto-Delete?

**Motivo:** Plugin é para SETUP INICIAL apenas!

Depois que WordPress está configurado, plugin não é mais necessário e seria só "peso morto" no servidor.

### Como Funciona

<Steps>
  <Step title="Instalou e ativou plugin">
    Contador de 6 horas começa
  </Step>

  <Step title="Você usa para configurar">
    Corrige tudo que precisa

    Verificações ficam verdes ✅
  </Step>

  <Step title="Após 6 horas">
    Plugin SE DESATIVA automaticamente

    E SE DELETA do servidor!
  </Step>
</Steps>

**No painel do plugin você vê:**
```
⏱️ Este plugin será removido automaticamente em 4 horas e 23 minutos.
```

<Info>
  **Quer manter ativo?** Basta desativar e reativar (contador reinicia para 6 horas)
</Info>

## Detalhes Técnicos

### O Que o Plugin Faz "Por Baixo dos Panos"

<AccordionGroup>
  <Accordion title="Verificação de Plugins" icon="magnifying-glass">
    **Código:**
    ```php
    // Verifica se Elementor existe na lista de plugins
    $installed_plugins = get_plugins();
    if (!isset($installed_plugins['elementor/elementor.php'])) {
      return 'not_installed';
    }

    // Verifica se está ativo
    if (!is_plugin_active('elementor/elementor.php')) {
      return 'not_active';
    }
    ```

    **Ação:** Lista todos plugins, verifica status
  </Accordion>

  <Accordion title="Instalação Automática de ProElements" icon="download">
    **Fluxo:**
    1. Faz request para ProElements.org
    2. Baixa arquivo ZIP
    3. Descompacta na pasta `/wp-content/plugins/`
    4. Ativa plugin automaticamente

    **Vantagem:** Usuário NÃO precisa fazer nada!
  </Accordion>

  <Accordion title="Ativação de Experimentos" icon="flask">
    **Código:**
    ```php
    // Ativa Container
    update_option('elementor_experiment-container', 'active');

    // Ativa Nested Elements
    update_option('elementor_experiment-nested-elements', 'active');

    // Regenera CSS do Elementor
    \Elementor\Plugin::instance()->files_manager->clear_cache();
    ```

    **Resultado:** Recursos ativados + cache limpo = funciona imediatamente!
  </Accordion>

  <Accordion title="Verificação de Limites PHP" icon="server">
    **Código:**
    ```php
    // Pega limite de memória
    $memory_limit = ini_get('memory_limit');

    // Converte para bytes (512M = 536870912 bytes)
    $memory_bytes = ebs_convert_to_bytes($memory_limit);

    // Compara com mínimo recomendado
    return $memory_bytes >= 536870912; // 512M
    ```

    **Nota:** Plugin APENAS verifica, não altera (precisa permissões de servidor)
  </Accordion>

  <Accordion title="Timer de Auto-Delete" icon="clock">
    **Como funciona:**
    1. Ao ativar, salva timestamp atual: `time()`
    2. Agenda evento WordPress: `wp_schedule_single_event(time() + 21600, 'ebs_auto_delete_event')`
    3. Após 6h (21600 segundos), evento dispara
    4. Plugin se desativa
    5. Plugin se deleta completamente

    **Código:**
    ```php
    function ebs_plugin_activation() {
      update_option('ebs_activation_time', time());
      wp_schedule_single_event(time() + 21600, 'ebs_auto_delete_event');
    }
    ```

    **Contador regressivo:** Interface mostra quanto tempo falta
  </Accordion>
</AccordionGroup>

## Código de Exemplo: O Que Plugin Gera

### Configurações que Plugin Ativa

**No banco de dados WordPress (wp_options):**

```sql
-- Ativa Containers
UPDATE wp_options
SET option_value = 'active'
WHERE option_name = 'elementor_experiment-container';

-- Ativa Nested Elements
UPDATE wp_options
SET option_value = 'active'
WHERE option_name = 'elementor_experiment-nested-elements';

-- Marca setup como finalizado
INSERT INTO wp_options (option_name, option_value)
VALUES ('ebs_setup_finalized', '1');
```

**Ações que dispara:**
```php
// Limpa cache do Elementor
\Elementor\Plugin::instance()->files_manager->clear_cache();

// Regenera arquivos CSS
\Elementor\Plugin::instance()->files_manager->regenerate_files();

// Sincroniza biblioteca de templates
\Elementor\Core\Common\Modules\Connect\Apps\Library::instance()->sync_library();
```

## Problemas Comuns

<AccordionGroup>
  <Accordion title="Plugin não aparece no menu" icon="eye-slash">
    **Causa:** Plugin não está ativo

    **Solução:**
    1. WordPress → Plugins
    2. Procure "Easy Setup"
    3. Clique em "Ativar"
  </Accordion>

  <Accordion title="Botão 'Corrigir' não funciona" icon="hand-pointer">
    **Causas possíveis:**
    - Permissões de arquivo incorretas
    - Hospedagem bloqueando instalação automática

    **Solução:**
    1. Tente novamente
    2. Se persistir, corrija manualmente:
       - [Instalar Elementor manualmente](/primeiros-passos/configuracao)
       - [Baixar ProElements](https://proelements.org)
  </Accordion>

  <Accordion title="PHP warnings aparecem em vermelho" icon="triangle-exclamation">
    **Causa:** Limites de PHP da hospedagem muito baixos

    **Solução:**
    1. Acesse cPanel da hospedagem
    2. MultiPHP INI Editor
    3. Aumente valores conforme [tutorial completo](/resolucao-problemas/limite-memoria)

    **Ou:** Entre em contato com suporte da hospedagem
  </Accordion>

  <Accordion title="Plugin sumiu antes de 6 horas" icon="clock">
    **Causa:** Você pode ter desativado acidentalmente

    **Solução:** Reinstale (não tem problema!)

    **Nota:** Se já corrigiu tudo, não precisa mais do plugin!
  </Accordion>
</AccordionGroup>
