## Fluxo de Atendimento: "Não consigo colar/importar"

Quando o usuário reportar problema ao colar ou importar elementos, siga este fluxo estruturado:

### Passo 1: Verificar Configurações Iniciais

<Steps>
  <Step title="Primeira Pergunta">
    **"Já fez as configurações iniciais do seu WordPress?"**

    Aguarde a resposta antes de prosseguir.
  </Step>

  <Step title="Se responder NÃO">
    **Resposta padrão:**

    > "Vou te enviar o passo a passo para configurar"

    **Enviar link:**
    ```
    https://app.easybuilder.com.br/onboarding
    ```

    <Info>
      Este link leva ao onboarding completo com todas as etapas de configuração inicial.
    </Info>
  </Step>

  <Step title="Se responder SIM">
    Continue para o Passo 2
  </Step>
</Steps>

### Passo 2: Identificar Tipo de Problema

<Steps>
  <Step title="Segunda Pergunta">
    **"Seu problema é só em colar as páginas ou as seções também?"**

    Esta pergunta ajuda a identificar se é problema generalizado ou específico.
  </Step>

  <Step title="Problema com PÁGINAS e SEÇÕES">
    **Resposta padrão:**

    > "Vou te enviar um link para te ajudar a resolver"

    **Enviar link:**
    ```
    https://app.easybuilder.com.br/onboarding/?step=03
    ```

    <Warning>
      Este link vai para a etapa 3 do onboarding que trata de problemas de colagem geral.
    </Warning>
  </Step>

  <Step title="Problema SOMENTE com SEÇÕES">
    **Resposta padrão:**

    > "Vou te enviar um link específico para seções"

    **Enviar link:**
    ```
    https://app.easybuilder.com.br/onboarding/?step=02
    ```

    <Info>
      Etapa 2 focada especificamente em problemas ao colar seções.
    </Info>
  </Step>
</Steps>

### Passo 3: Problema Persiste?

<Steps>
  <Step title="Se o problema continuar">
    **Enviar troubleshooting avançado:**

    ```
    https://app.easybuilder.com.br/onboarding/?step=04
    ```

    <Warning>
      Etapa 4 contém soluções avançadas para casos mais complexos.
    </Warning>
  </Step>

  <Step title="Se ainda não resolver">
    **Escalar para suporte humano:**

    > "Vou transferir você para um especialista que vai te ajudar diretamente."

    **Ações:**
    - Anotar todos os passos já tentados
    - Informar versão do WordPress e Elementor
    - Screenshot do erro se possível
    - Informar navegador utilizado
  </Step>
</Steps>

## Informações para Coleta

Quando precisar escalar, colete estas informações:

<Tabs>
  <Tab title="Dados Técnicos">
    - **WordPress:** Versão
    - **Elementor:** Versão (Free/Pro/Pro Elements)
    - **Tema:** Qual está usando
    - **Navegador:** Chrome/Edge/Brave/etc e versão
    - **Hospedagem:** Hostinger/Stay/Outra
    - **PHP:** Versão (se souber)
  </Tab>

  <Tab title="Histórico Tentativas">
    - Links já enviados
    - Etapas já tentadas
    - Mensagens de erro (se houver)
    - Screenshot ou vídeo do problema
    - Último passo que funcionou
  </Tab>

  <Tab title="Contexto Usuário">
    - Iniciante ou experiente?
    - Primeira vez usando Easy Builder?
    - Já funcionou antes?
    - WordPress novo ou antigo?
    - Pode instalar backup?
  </Tab>
</Tabs>

## Casos Especiais

<AccordionGroup>
  <Accordion title="Usuário com pressa" icon="clock">
    **Ação rápida:**
    1. Enviar diretamente etapa 3 (mais abrangente)
    2. Se não resolver em 5min, escalar imediatamente
    3. Priorizar atendimento humano
  </Accordion>

  <Accordion title="Múltiplas tentativas falhadas" icon="repeat">
    **Ação:**
    1. Verificar se não é problema de hospedagem
    2. Perguntar sobre limite de memória PHP
    3. Considerar reinstalação com backup
    4. Escalar para suporte técnico avançado
  </Accordion>

  <Accordion title="Problema no navegador" icon="browser">
    **Verificar:**
    - Extensão instalada corretamente?
    - Navegador atualizado?
    - Cache limpo?
    - Testar em modo anônimo
    - Testar em outro navegador
  </Accordion>

  <Accordion title="Problema de permissões" icon="lock">
    **Verificar:**
    - Usuário é administrador do WordPress?
    - Elementor instalado e ativado?
    - Pro Elements ou Elementor Pro ativo?
    - Licença do Easy Builder válida?
  </Accordion>
</AccordionGroup>
