## Antes de Começar

Se você **já tem WordPress instalado** e quer usar o Easy Builder, siga este guia passo a passo para garantir que tudo funcione perfeitamente.

<Info>
  **Importante:** São apenas 5 passos rápidos! Se pular algum, o Easy Builder pode não funcionar corretamente.
</Info>

## Passo 1: Configurações Iniciais

<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/DL0975hhUL8"
  title="01. Configurações Iniciais"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>

### O que fazer:

<Steps>
  <Step title="1. Atualizar WordPress">
    **WordPress → Painel → Atualizações**

    - Verificar versão atual
    - Se disponível: Clicar em **"Atualizar Agora"**
    - **Importante:** Se WordPress muito antigo, faça backup antes!
  </Step>

  <Step title="2. Verificar Elementor">
    **Plugins → Plugins Instalados**

    Procure por **"Elementor"**:
    - ✅ Deve estar instalado e atualizado
    - Se não tiver: Adicionar Plugin → Buscar "Elementor" → Instalar

    <Check>
      Elementor é OBRIGATÓRIO para o Easy Builder funcionar!
    </Check>
  </Step>

  <Step title="3. Elementor PRO ou Pro Elements">
    Você precisa de UMA dessas opções:

    **Opção 1: Elementor PRO** (pago)
    - Se você tem licença oficial
    - Mantenha atualizado

    **Opção 2: Pro Elements** (gratuito - Recomendado!)
    - Acesse: [ProElements.org](https://proelements.org)
    - Faça download do plugin
    - Plugins → Adicionar Novo → **Enviar Plugin**
    - Selecione arquivo baixado → Instalar

    <Warning>
      **NÃO use Elementor PRO craqueado!** Use Pro Elements (gratuito e seguro). Funciona perfeitamente com Easy Builder!
    </Warning>
  </Step>
</Steps>

### Resumo do Vídeo:

✅ Atualizar WordPress (Painel → Atualizações)
✅ Instalar Elementor (se não tiver)
✅ Instalar Elementor PRO OU Pro Elements
✅ Fazer backup se WordPress muito antigo

## Passo 2: Configurar Recursos do Elementor

<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/C3DLGlfoxYU"
  title="02. Configurando seu Elementor"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>

### O que fazer:

<Steps>
  <Step title="1. Atualizar plugins">
    **Plugins → Plugins Instalados**

    - Elementor: Clicar em **"Atualizar"**
    - Elementor PRO/Pro Elements: Clicar em **"Atualizar"**
  </Step>

  <Step title="2. Abrir configurações">
    **Elementor → Configurações**

    (No menu lateral esquerdo)
  </Step>

  <Step title="3. Ativar recursos">
    Clique na aba **"Recursos"**

    **Ativar TUDO, exceto:**
    - ❌ **Marcação Otimizada** (DESATIVE! Causa conflitos)

    <Warning>
      Marcação Otimizada causa conflito com templates! Mantenha DESATIVADA.
    </Warning>
  </Step>

  <Step title="4. Escolher barra do editor (opcional)">
    **Preferência de interface:**

    **Barra Superior (padrão):**
    - Interface moderna
    - Mais espaço vertical

    **Barra Lateral (clássica):**
    - Versão antiga
    - Alguns preferem por costume
    - Configurar: Recursos → **"Barra Superior do Editor"** → Inativo

    <Tip>
      Recomendamos manter **Barra Superior** (padrão). Mais moderna e organizada!
    </Tip>
  </Step>

  <Step title="5. Salvar alterações">
    Role até o final → **"Salvar Alterações"**
  </Step>
</Steps>

### Resumo do Vídeo:

✅ Atualizar Elementor e Elementor PRO/Pro Elements
✅ Elementor → Configurações → Recursos
✅ Ativar TUDO (exceto Marcação Otimizada)
✅ Salvar Alterações

## Passo 3: Última Configuração Essencial

<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/j6ujQEEIJy8"
  title="03. Última Configuração"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>

### O que fazer:

<Steps>
  <Step title="1. Abrir ferramentas">
    **Elementor → Ferramentas**

    (No menu lateral esquerdo)
  </Step>

  <Step title="2. Gerar arquivos novamente">
    Procure: **"Gerar arquivos e dados novamente"**

    Clique no botão → Aguarde concluir
  </Step>

  <Step title="3. Sincronizar biblioteca">
    Procure: **"Sincronizar Biblioteca"**

    Clique no botão → Aguarde concluir

    <Check>
      Essas duas ações são ESSENCIAIS! Sem elas o Easy Builder não cola elementos.
    </Check>
  </Step>

  <Step title="4. Testar se funcionou">
    **Criar página de teste:**

    1. WordPress → Páginas → **Adicionar Nova**
    2. Nome: "Teste Easy Builder"
    3. **Editar com Elementor**
    4. Abrir Easy Builder (extensão no topo do navegador)
    5. Fixar extensão (clique no pin 📌)
    6. Easy Builder → Sessões ou Páginas → **Copiar**
    7. No Elementor: Área cinza → Botão direito → **"Colar de outro site"**
    8. **Ctrl + V**

    **Funcionou?** Template importado = Tudo certo! ✅

    **NÃO funcionou?** Vá para o Passo 4 (limitação de PHP)
  </Step>
</Steps>

### Resumo do Vídeo:

✅ Elementor → Ferramentas
✅ Gerar arquivos e dados novamente
✅ Sincronizar biblioteca
✅ Testar importação de template

## Passo 4: Corrigir Limitação de PHP (Se necessário)

<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/fwFTzhqyVa0"
  title="04. Esse erro permaneceu? Faça isso!"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>

### Quando fazer este passo:

<Warning>
  **Só faça se o teste do Passo 3 NÃO funcionou!** Se templates não colam ou dá erro, sua hospedagem tem limitação de PHP.
</Warning>

### Solução completa:

Acesse a página específica com tutorial detalhado:

<Card title="Corrigir Limite de Memória PHP" icon="memory" href="/resolucao-problemas/limite-memoria">
  Tutorial completo de como aumentar limites de PHP no cPanel
</Card>

### Código para adicionar no .htaccess:

Se você tem acesso ao arquivo `.htaccess` da sua hospedagem, adicione:

```apache
# Easy Builder config
php_value max_execution_time 600
php_value max_input_time 600
php_value memory_limit 1024M
php_value upload_max_filesize 512M
php_value post_max_size 512M
```

**Como adicionar:**

<Steps>
  <Step title="Acessar arquivos">
    Via FTP ou Gerenciador de Arquivos do cPanel
  </Step>

  <Step title="Encontrar .htaccess">
    Pasta raiz: `public_html/.htaccess`

    (Arquivo pode estar oculto - ative "Mostrar arquivos ocultos")
  </Step>

  <Step title="Editar arquivo">
    Abra o arquivo → Cole o código no FINAL

    Salve e feche
  </Step>

  <Step title="Testar novamente">
    Volte ao WordPress e teste colar template

    **Funcionou?** Problema resolvido! ✅
  </Step>
</Steps>

<Tip>
  **Não tem acesso ao .htaccess?** Entre em contato com o suporte da sua hospedagem pedindo para aumentar os limites de PHP.
</Tip>

## Problemas Comuns

<AccordionGroup>
  <Accordion title="Template não cola / Dá erro" icon="circle-exclamation">
    **Causa:** Limitação de PHP da hospedagem

    **Solução:**
    1. Aumente limites no cPanel (MultiPHP INI Editor)
    2. Ou adicione código no .htaccess
    3. Ou entre em contato com hospedagem

    [Ver solução completa →](/resolucao-problemas/limite-memoria)
  </Accordion>

  <Accordion title="Easy Builder não abre" icon="puzzle-piece">
    **Causas possíveis:**
    - Extensão não instalada
    - Extensão desativada
    - Navegador incompatível (Firefox não funciona!)

    **Solução:**
    - Use Chrome, Opera ou Edge
    - Verifique se extensão está ativa
    - Fixe extensão no topo (clique no 📌)

    [Instalar extensão →](https://link.easybuilder.com.br/instalar-eb)
  </Accordion>

  <Accordion title="Elementos vêm desconfigura dos" icon="palette">
    **Causa:** Cores e fontes globais não definidas

    **Solução:**
    - Elementor → Configurações do Site → Estilos Globais
    - Configure cores primárias, secundárias, texto, destaque
    - Configure fontes primárias, secundárias, texto, destaque

    [Ver tutorial →](/resolucao-problemas/templates-desconfigurados)
  </Accordion>
</AccordionGroup>
