## Como Economizar Dias de Trabalho

Antes do Easy Builder, montar uma página era quase uma saga épica. O cliente chegava, aí tinha briefing, pagamento, nota, grupo de WhatsApp, Drive, ClickUp, planilha financeira, revisão de arquivos, validação... tudo isso **antes** de começar o design.

<Warning>
  **O caos real do método tradicional:**

  Cria Figma → monta layout da primeira sessão → aprova internamente → manda pro cliente → cliente aprova → aí sim faz o resto da página no Figma → aprova de novo → começa implementação no Elementor → cria páginas → exporta arquivos → implementa manualmente cada detalhe → revisa tudo → otimiza → configura plugins → ativa cache → insere formulários, cookies, políticas → faz backup → coleta depoimento → salva portfólio → atualiza financeiro → só então entrega.

  **Resultado:** Dias de trampo só pra uma página.
</Warning>

### Processo Otimizado:

<Steps>
  <Step title="Onboarding">
    Cliente preenche briefing e paga. Igual ao processo tradicional.
  </Step>

  <Step title="Desenvolvimento">
    Instala o backup do Easy Builder no WordPress.

    **Já vem com tudo:**
    - Elementor + Pro Elements
    - Plugins essenciais
    - Pré-carregamento de pixel

    - Logo

## Criação de Imagens de Fundo

### Para Desktop:

<iframe
  width="100%"
  height="400"
  src="https://www.youtube.com/embed/7pIbuzBIx98"
  title="Como criar imagens do tamanho certo"
  frameBorder="0"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture"
  allowFullScreen
></iframe>

<Steps>
  <Step title="Monte a seção primeiro">
    1. Abre o Elementor
    2. Copia e cola a seção
    3. Altera textos, cores, fonte global
    4. Deixa tudo ajustado
  </Step>

  <Step title="Descubra o tamanho">
    Clica na seção → **Layout > Altura mínima**

    Ex: Se está em **875px**, esse é o valor da altura
  </Step>

  <Step title="Crie a imagem">
    Photoshop ou Figma:
    - Largura: **1920px**
    - Altura: **875px** (ou o valor que descobriu)

    **Formato:** Sempre `.webp` para melhor performance
  </Step>

  <Step title="Converta para WebP">
    Use [Squoosh.app](https://squoosh.app)

    **Configuração:**
    - Formato: WebP
    - Qualidade: 64-80
    - Tamanho: Até 100KB
  </Step>

  <Step title="Aplique no Elementor">
    1. Clica na seção
    2. **Estilo > Tipo de Fundo > Clássico**
    3. Envia a imagem .webp
    4. Marca opção **"Capa"** (Cover)
    5. **Posição:** Top Center
    6. **Repetição:** No Repeat
  </Step>
</Steps>

<Steps>
  <Step title="Use extensão de print">
    Instala **Lightshot** no PC

    1. Cola o print no Photoshop
    2. **Imagem > Tamanho da imagem**
    3. Muda largura para **1080px**
    4. Mantém proporção ativa (pininho)
  </Step>

  <Step title="Adicione elementos">

    - Cole personagem
    - Adicione fundos extras

    - Use máscaras e guias

    **Arquivo > Exportar > Salvar para Web** (Ctrl + Alt + Shift + S)

    - Formato: JPEG

  </Step>

    Seção > **Estilo > Fundo**

    **Configuração:**
    - Posição: Top Center
    - Repetição: No Repeat
    - Tamanho: Capa (Cover)
  </Step>
</Steps>

### Técnica de Fundos Contínuos:

<Steps>
  <Step title="Mesma altura nas seções">
    **Crítico:** Duas seções com **MESMA largura e altura**

    Ex: Primeira = 614px, Segunda = 614px

    **Sem um pixel a mais ou a menos!**
  </Step>

  <Step title="Criar arquivo no Photoshop">
    - Largura: **1920px**
    - Altura: **Soma das duas seções** (ex: 614 + 615 = 1229px)
  </Step>

  <Step title="Usar guia horizontal">
    1. Cria **guia horizontal** onde a primeira seção termina (ex: 614px)
    2. Cria arte normalmente (personagem, fundo, luz, sombra)
    3. Parte de cima: primeira seção
    4. Embaixo da guia: segunda seção (continuação)
  </Step>

  <Step title="Fatiar por Guias">
    **Ferramenta de corte** → **"Fatiar por Guias"**

    Photoshop divide exatamente onde você colocou a guia!
  </Step>

  <Step title="Exportar separadamente">
    **Arquivo > Exportar > Salvar para Web**

    - Seleciona cada imagem individualmente
    - Qualidade: Muito Alta
    - Converte pra WebP (Squoosh)
    - Mantém: 60-100KB
  </Step>

  <Step title="Aplicar no Elementor">
    **Primeira seção (614px):**
    - Estilo > Fundo > Primeira imagem
    - Top Center / No Repeat / Cover

    **Segunda seção (615px):**
    - Estilo > Fundo > Segunda imagem
    - Top Center / No Repeat / Cover

    **Pronto!** Fundo parece um só, contínuo, perfeito!
  </Step>
</Steps>

<Tip>
  **No mobile:** Evite emendas milimétricas. Use degradê ou sombra para suavizar transições entre dispositivos diferentes.
</Tip>

### Processo Completo:

<Steps>
  <Step title="1. Busque referências">
    Vai no **Pinterest** ou Google Imagens

    Busca por referências visuais do tema da página

    Ex: "tribunal", "advogado escritório", "consultório moderno"
  </Step>

  <Step title="2. Use Easy Image">
    Copia uma das imagens de referência

    Vai até a IA **Easy Image** (dentro da Área de Membros)

    Pede: "Faça um prompt para gerar uma imagem parecida com essa"

    Ela entrega um prompt em português
  </Step>

  <Step title="3. Traduza para inglês">
    Peça para a IA traduzir o prompt

    **Por quê?** ImageFX (Google) entende melhor comandos em inglês
  </Step>

  <Step title="4. Gere no ImageFX">
    Acesse: [ImageFX](https://labs.google/fx/pt/tools/image-fx)

    Cole o prompt traduzido

    Selecione formato: **Paisagem (Landscape)**

    **Pronto!** A IA gera imagens lindas que servem como base
  </Step>

  <Step title="5. Edite a imagem">
    Pode fazer em: Canva, Figma, Photoshop ou até Paint

    **Ajustes:**
    - Redimensione pro tamanho da seção (1920 x altura)
    - Print da seção do Elementor como guia
    - Modo de mesclagem "Divisão" para ver layout por baixo
  </Step>

  <Step title="6. Adicione contraste">
    Quer destacar o texto?

    Adiciona **degradê preto com transparência** do lado esquerdo

    Assim o texto ganha destaque e o fundo não briga
  </Step>
</Steps>

    Exporte a imagem finalizada
  </Step>

  <Step title="Use Squoosh">
    [Squoosh.app](https://squoosh.app)

    1. Arrasta sua imagem
    2. Muda formato para **WebP**
    3. Ajusta qualidade: **60-80**
    4. Meta: **60KB a 100KB**
    5. Salva
  </Step>

  <Step title="Suba no Elementor">
    Seção > **Estilo > Fundo**

    **Configuração:**
    - Posição: **Top Center**
    - Repetição: **No Repeat**
    - Tamanho: **Capa (Cover)**
  </Step>
</Steps>

<Info>
  **Para mobile:** Mesma lógica, mas formato vertical

  Exemplo: 1080 x 1300px

  Degradê de cima para baixo para manter legibilidade
</Info>
