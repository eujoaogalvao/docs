## Backup do WordPress: Quando Usar?

O Easy Builder oferece um **WordPress pré-configurado** com todos os plugins e otimizações já aplicadas.

<AccordionGroup>
  <Accordion title="Quando USAR o Backup" icon="check">
    **Use o backup se você:**
    - Está começando um projeto do zero
    - Quer economizar tempo de configuração (45+ minutos)
    - Precisa de uma base confiável e testada
    - Vai criar um novo site do zero
    - Tem um WordPress que pode ser totalmente substituído
  </Accordion>

  <Accordion title="Quando NÃO USAR o Backup" icon="xmark">
    **NÃO use o backup se você:**
    - Já tem um site WordPress funcionando
    - Tem conteúdo que não pode perder
    - Prefere configurar manualmente
    - O WordPress já está em produção

    <Warning>
      O backup **SOBRESCREVE TUDO** no WordPress. Use apenas em instalações novas!
    </Warning>
  </Accordion>

  <Accordion title="Como Usar o Backup" icon="book">
    <Card title="Tutorial Completo do Backup" icon="download" href="/funcionalidades/backup-configurado">
      Guia passo a passo de instalação e uso
    </Card>
  </Accordion>
</AccordionGroup>
