## O que é o Easy Coder?

O **Easy Coder** é uma funcionalidade dentro do Easy Builder que funciona como um "ajudante técnico" que entende de código, mas sem ser aquele chato que fala difícil. Ele é uma **inteligência artificial** embutida na plataforma que te dá suporte na hora de personalizar os elementos das páginas, mesmo que você não tenha nenhum conhecimento de programação.

<Info>
  **Acesse:** Para usar o Easy Coder, basta acessar o módulo "IAs do Easy Builder" dentro da sua área de membros.
</Info>

## Como Funciona?

Você tá lá, no editor do Elementor, montando seu site com o Easy Builder, e precisa ajustar um efeito, uma borda, ou mudar alguma parada no CSS. Em vez de sair caçando código no Google, você chama o Easy Coder, diz o que quer fazer e **ele gera o código pra você, mastigadinho**. Tipo um tradutor de ideias para CSS/HTML.

<Steps>
  <Step title="Descreva o que quer">
    Explique em linguagem natural o efeito ou customização desejada
  </Step>

  <Step title="IA gera o código">
    O Easy Coder cria o código CSS/HTML/JS para você
  </Step>

  <Step title="Copie e cole">
    Copie o código gerado e cole no Elementor
  </Step>

  <Step title="Ajuste se necessário">
    Refine no próprio painel do Elementor se quiser
  </Step>
</Steps>

## Dicas de Uso

<Tip>
  **Seja específico:** Quanto mais detalhes você der, melhor será o código gerado. Em vez de "deixa bonito", diga "adiciona sombra azul de 10px com opacidade 50%"
</Tip>

<Tip>
  **Teste incrementalmente:** Peça uma função por vez e teste antes de pedir a próxima
</Tip>

<Tip>
  **Refine com feedback:** Se o resultado não ficou perfeito, peça ajustes específicos
</Tip>

## Limitações

<Warning>
  **O Easy Coder é ótimo para:**
  - Customizações visuais
  - Efeitos e animações
  - Ajustes de layout
  - Interações simples

  **Não é ideal para:**
  - Sistemas complexos
  - Backend e banco de dados
  - Integrações avançadas
  - Funcionalidades que exigem PHP
</Warning>
