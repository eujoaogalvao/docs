## Como Usar na Prática

<Tabs>
  <Tab title="Copy + Copywriting">
    ### Criação de Textos Persuasivos

    **Você pode pedir:**
    - Reescrever headline com mais punch
    - Escrever seções de página (Hero, Benefícios, Prova, CTA)
    - Criar VSL Script, roteiro de Reels, anúncios
    - Ajustar tom de voz (mais ousado, empático, técnico)
    - Criar promessa, premissa, analogia
    - Usar fórmulas: AIDA, PAS, 4Ps

    **Exemplos:**

    ```
    "Cria 3 versões de headline para uma página de vendas
    de curso de Web Designer, com foco em liberdade e faturamento"

    "Reescreve esse parágrafo com mais impacto, usando
    linguagem direta e com analogia"

    "Transforma essa promessa genérica em uma promessa
    com número e visual forte"
    ```
  </Tab>

  <Tab title="Design + Estrutura">
    ### Organização de Páginas

    **Você pode pedir:**
    - Organização lógica da página (ordem das seções)
    - Sugestões de elementos visuais
    - Exemplos de imagens para ilustrar conceito
    - Dicas de UX/UI
    - Análise crítica de página publicada

    **Exemplos:**

    ```
    "Qual a melhor ordem de seções para uma landing page
    de infoproduto de emagrecimento?"

    "Sugere uma ideia visual forte para a seção de
    'transformação do cliente'"

    "Essa página tem um bom UX? O que você mudaria
    pra melhorar conversão?"
    ```
  </Tab>

  <Tab title="Vendas + Estratégia">
    ### Posicionamento e Argumentação

    **Você pode pedir:**
    - Pitch de venda lógico
    - Argumento de valor
    - Comparativo com concorrentes
    - Criação de persona
    - Gatilhos e ângulos de comunicação
    - Roteiro de story, reels ou VSL com CTA

    **Exemplos:**

    ```
    "Cria um comparativo entre Web Designer tradicional
    e Web Builder, com foco em produtividade"

    "Cria um pitch lógico com dores, solução, benefícios
    e CTA para um curso de Web Builder"

    "Me dá 5 ideias de Reels com humor sutil para
    posicionar Easy Builder como superior"
    ```
  </Tab>

  <Tab title="Educação">
    ### Aprenda Enquanto Usa

    **Você pode pedir:**
    - Explicações técnicas de copy, design, vendas, SEO
    - Resumo de aula ou material
    - Checklist de implementação
    - Tradução de conceito técnico
    - Simulação de reunião com cliente
    - Roteiro de feedback

    **Exemplos:**

    ```
    "Explica como funciona o funil antiprospecção em 5 passos"

    "Cria um checklist de tudo que preciso revisar antes
    de entregar uma landing page"

    "Como explico para um cliente leigo o que é
    layout responsivo e por que importa?"
    ```
  </Tab>

  <Tab title="Operação">
    ### Processos e Entregas

    **Você pode pedir:**
    - Checklist de onboarding
    - Roteiro de reunião com cliente
    - Estrutura de proposta comercial
    - Texto de e-mail de entrega
    - Sugestão de cronograma
    - Planilha de controle de demandas

    **Exemplos:**

    ```
    "Cria um texto de WhatsApp para entregar o site
    pro cliente com elegância"

    "Qual a sequência lógica de entrega de um
    projeto Web Builder?"

    "Escreve uma proposta comercial que mostra
    o ROI de um site feito com Easy Builder"
    ```
  </Tab>
</Tabs>

## Modelo de Prompt Eficiente

Para obter os melhores resultados, use este modelo:

<Card title="Template de Prompt" icon="code">
```
Quero que você aja como [copywriter, estrategista, redator].

Estou criando [landing page, proposta, anúncio] para
[público-alvo + dores].

O objetivo é [resultado desejado].

O tom deve ser [direto, emocional, técnico].

Crie [headline, argumento, lista, analogia].
```
</Card>

**Exemplo prático:**

<Card title="Exemplo Completo" icon="lightbulb">
```
Quero que você aja como copywriter persuasivo.

Estou criando uma landing page para web designers
iniciantes que querem aumentar produtividade e faturar mais.

O objetivo é capturar leads para teste gratuito.

O tom deve ser direto e motivacional.

Crie 5 headlines impactantes.
```
</Card>

## Dicas para Melhores Resultados

<AccordionGroup>
  <Accordion title="Contexto é rei" icon="crown">
    Quanto mais você contextualizar, melhor a resposta.

    **❌ Ruim:**
    "Faz uma headline pra minha página"

    **✅ Bom:**
    "Faz uma headline para landing page que vende curso de Web Designer para iniciantes, com foco em liberdade financeira e primeira renda no digital. Público: homens 25-35 anos cansados da CLT"
  </Accordion>

  <Accordion title="Itere e refine" icon="arrows-rotate">
    Use como um diálogo, não como Google.

    Peça melhorias, mais versões, refine.

    **Exemplos:**
    - "Melhora essa versão com mais punch emocional"
    - "Faz uma versão mais simples, como se fosse pra um primo leigo"
    - "Agora com tom mais provocativo"
  </Accordion>

  <Accordion title="Você é o maestro" icon="wand-magic-sparkles">
    O ChatGPT não substitui você — **potencializa você**.

    Você é responsável pelo sucesso do projeto. Ele é um instrumento poderoso que toca o que você pedir, no tom que escolher.
  </Accordion>
</AccordionGroup>
