## O que é o Copy Easy Builder?

O Copy Easy Builder não é "mais um robozinho que responde e-mails". Ele é um **sócio estratégico** de copywriting com acesso completo à base de dados do Easy Builder.

<Check>
  É seu estagiário de luxo com doutorado em copy, vendas e estruturação de ideias. Mas só se você souber mandar.
</Check>

## O que essa IA faz?

<AccordionGroup>
  <Accordion title="1. Copywriting sob demanda" icon="pen-nib">
    - Pitches, headlines, chamadas
    - Ângulos de abordagem
    - Ganchos de e-mail
    - Argumentos de vendas
    - Storytelling

    Pode escrever com o tom Lorenzi: direto, provocativo, sarcástico, com autoridade e senso estratégico.

    Pode adaptar o tom para outros contextos: institucional, didático, emocional.
  </Accordion>

  <Accordion title="2. Organiza o caos mental" icon="brain">
    - Ajuda a transformar rascunhos bagunçados em estrutura lógica
    - Pega blocos soltos de ideias e estrutura como pitch, roteiro, aula, post ou artigo
  </Accordion>

  <Accordion title="3. Cria documentação interna" icon="book">
    - Cria manuais, listas de processos
    - Comparativos, instruções de uso
    - Guias didáticos com linguagem clara
  </Accordion>

  <Accordion title="4. Explica produtos" icon="box">
    - Explica o que é o Easy Builder, os planos, as IAs
    - Diferença entre PRO e WEB
    - Funcionalidades detalhadas
    - Transforma informações técnicas em linguagem acessível
  </Accordion>

  <Accordion title="5. Rebate objeções" icon="shield-check">
    - Sabe exatamente quais são as desculpas de cada perfil
    - Pode contra-argumentar com lógica, sarcasmo ou empatia
  </Accordion>

  <Accordion title="6. Cria conteúdo com base em arquivos" icon="folder">
    Tem acesso aos documentos internos:
    - Dores, Benefícios, Comparativos
    - Perfis de Cliente
    - Funcionalidades

    Basta pedir: "cria uma página de vendas com base nos arquivos do Easy Builder"
  </Accordion>

  <Accordion title="7. Planejamento estratégico" icon="chess">
    - Sugerir nomes de produtos
    - Posicionamento
    - Sequência de e-mails
    - Tópicos de conteúdo
    - Arquitetura de oferta
  </Accordion>

  <Accordion title="8. Atendimento e suporte" icon="headset">
    - Simular respostas para dúvidas técnicas e comerciais
    - Traduzir linguajar técnico para leigos
  </Accordion>

  <Accordion title="9. Variações de copy" icon="repeat">
    - Reescrever headline com diferentes tons
    - Provocativo, institucional, emocional, aspiracional, humorístico
    - Perfeito para testes A/B
  </Accordion>

  <Accordion title="10. Mapeia funil" icon="filter">
    - Organizar sequência de conteúdo, e-mails, vídeos
    - Conduzir cliente da dor até a venda
    - Dividir por consciência (desconhecido > consciente > comprador)
  </Accordion>

  <Accordion title="11. Extrai argumentos" icon="file-magnifying-glass">
    - Recebe texto solto, PDF ou transcrição de vídeo
    - Extrai: dores, promessas, provas, diferenciais, objeções
    - Ideal para transformar material cru em peça comercial
  </Accordion>
</AccordionGroup>

## Melhor Forma de Usar

<Steps>
  <Step title="Seja específico">
    Comece com: "Quero criar X para o perfil Y com foco no argumento Z"
  </Step>

  <Step title="Defina o objetivo">
    É para página? E-mail? Pitch de venda? Treinamento?
  </Step>

  <Step title="Diga o tom desejado">
    Direto, emocional, didático, agressivo, sofisticado, sarcástico...
  </Step>

  <Step title="Peça variações">
    Teste variações, ganchos diferentes ou explore outros ângulos
  </Step>

  <Step title="Refine">
    "Esse tópico está bom. Reescreve o segundo parágrafo com mais punch"
  </Step>
</Steps>

## O que ele NÃO faz

<Warning>
  - ❌ Ler pensamentos vagos. Seja direto
  - ❌ Aceitar abreviações. Escreva como profissional
  - ❌ Criar ideias boas com brief fraco. Contexto é rei
  - ❌ Fingir que sabe quando não sabe. Vai pedir mais info
</Warning>

## Resumo Final

O Copy Easy Builder é um gerador de argumentos, ideias e textos com acesso a toda a base interna do produto Easy Builder.

<Check>
  Serve para ajudar o time a **vender mais, explicar melhor, criar mais rápido** e ter consistência de linguagem e posicionamento.
</Check>

Não é um robô burro que adivinha coisas. É uma ferramenta de **output acelerado com direção clara**.

<Tip>
  Se você sabe o que quer, ele entrega melhor do que qualquer outro redator do mundo. Se você não sabe, ele te ajuda a descobrir.
</Tip>

**Mas não trate como mágica. Trate como parte do seu sistema de guerra.**

Use sem moderação. Com responsabilidade. E com briefing decente.
