  <Accordion title="O que é o Easy Builder? [Para não leigos]" icon="wrench">
    O Easy Builder é uma extensão de navegador criada para quem desenvolve sites e landing pages no WordPress usando Elementor.

    **A proposta:** você não precisa mais começar uma página do zero. Em vez de montar cada seção manualmente, você simplesmente escolhe a estrutura que precisa e cola direto no editor.

    **Diferenciais:**
    - Motor centralizado com recursos salvos
    - Integração com inteligência artificial
    - Backup completo do WordPress já configurado
    - Comunidade ativa com suporte
    - Sistema de salvamento e reutilização
  </Accordion>

  <Accordion title="O que é o Easy Builder? [Para leigos]" icon="rocket">
    Quando você quer criar um site, geralmente usa **WordPress** e dentro dele o **Elementor** (editor visual).

    O problema? Montar do zero consome muito tempo.

    O **Easy Builder** é uma **extensão que você instala no navegador** e ganha acesso a uma **biblioteca gigante de partes prontas de site** — blocos de títulos, depoimentos, rodapés, páginas inteiras — tudo pronto pra você **copiar e colar**.

    **Inclui:**
    - Backup do WordPress já configurado
    - 3 Inteligências Artificiais (layout, textos, código)
    - Área para salvar seus próprios blocos
    - Comunidade ativa
  </Accordion>

  <Accordion title="O que é o Método Anti-Prospecção?" icon="magnet">
    O método Anti-Prospecção é um sistema estruturado que ensina profissionais criativos a **atraírem clientes qualificados automaticamente**, sem precisar rodar tráfego pago ou spammar DM.

    **Espinha dorsal do método:**
    - Posicionamento estratégico
    - Funil de captação automatizada
    - Autoridade construída por verdade
    - Vendas com postura de liderança

    É vender com dignidade, sem correr atrás de ninguém. **É ser desejado, não disponível.**
  </Accordion>
</AccordionGroup>

## Compatibilidade e Integração

<AccordionGroup>
  <Accordion title="O Easy Builder funciona fora do WordPress?" icon="wordpress">
    ❌ **Não. O Easy Builder NÃO funciona fora do WordPress.**

    **Por quê?**
    - Foi criado para ser um turbo no Elementor
    - Elementor é um plugin do WordPress
    - Depende do DOM do Elementor para funcionar
    - Usa a arquitetura do WordPress

    É um **acelerador de estrutura** que vive dentro do universo WordPress + Elementor.
  </Accordion>

  <Accordion title="Funciona em qual navegador?" icon="browser">
    ✅ Funciona em todos os navegadores **exceto Mozilla Firefox**

    **Navegadores suportados:**
    - Google Chrome
    - Microsoft Edge
    - Brave
    - Opera
    - Arc
  </Accordion>
</AccordionGroup>
